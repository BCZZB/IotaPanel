# iotapanel-ai-guardian

AI 守护 —— IotaPanel 的极低占用 AI 运维探针插件。

## 特性

- **微探针常驻**：独立低占用探针（约 2~6MB 内存）定时采集 CPU / 内存 / 磁盘 / 网络 / 各插件 RSS 指标
- **AI 周期研判**：每个周期将采样数据 + 插件状态交给 AI 模型（OpenAI 兼容接口）分析，输出结论 / 问题 / 建议 / 动作
- **优雅插件管控**：内置 MCP 服务（JSON-RPC over HTTP），可优雅启停插件市场的其他插件，支持 AI 自动处置
- **按需唤醒主进程**：主进程非常驻，面板反代请求时冷启动、空闲自动退出，把资源还给服务器
- **纯 Go 零依赖**：静态编译单二进制，无任何运行时依赖

## 架构

```
┌────────────┐   唤醒(按需)   ┌────────────┐
│  面板网关   │ ────────────▶ │  主进程     │  API / Web UI / MCP
└────────────┘               └─────┬──────┘
        │ 代理                      │ 领养/拉起
        ▼                          ▼
┌─────────────────────────────────────────┐
│  探针 (常驻, ~2MB)                        │
│  采样 → 本地存储 → 周期调用 AI → 自动处置  │
└─────────────────────────────────────────┘
```

## 安装

面板「插件」页 → URL 安装，粘贴 Release 附件直链（tar.gz，可选填 SHA256）：

```
https://github.com/BCZZB/iotapanel-ai-guardian/releases/download/v0.1.0/ai-guardian-0.1.0-linux-amd64.tar.gz
```

## 配置

安装后进入「AI 守护」页面 → 设置，填入：

| 配置 | 说明 |
|------|------|
| base_url | OpenAI 兼容接口地址，如 `https://api.openai.com/v1` |
| api_key | 模型 API Key |
| model | 模型名，如 `gpt-4o-mini` |

## 构建

```sh
./build.sh
```
