站点设置

自动申请免费证书
使用「SSL 证书」设置中选择的免费 CA（Let's Encrypt / ZeroSSL / Buypass…）， 自动完成域名验证（HTTP-01）并签发证书，全程无需人工操作；签发后到期自动续期。
前提：域名已解析到本服务器，且公网 80 端口可达（NAT 环境需在服务商处映射 80 → 本机 80）； IP 直连证书为 Let's Encrypt shortlived（约 6 天有效期，自动续期无感覆盖）。
粘贴 PEM 格式的证书与私钥（支持 Let's Encrypt / 自签证书），保存后立即启用 HTTPS（SNI）。
强制 HTTPS（HTTP 301 跳转）

PHP 运行时

启用 PHP 运行时
按需启动：首个 PHP 请求才拉起 php-fpm，空闲自动停止，不用时零内存占用
低占用建议 1-4；ondemand 模式，空闲 worker 10 秒自动退出
无 PHP 请求超过该时长后，整个 php-fpm 自动停止

删除网站

仅默认沙箱目录可被删除；自定义目录与证书私钥会保留/清理规则见提示。

创建数据库

字母开头，仅含字母 / 数字 / 下划线；utf8mb4 编码
8-64 位，不含引号 / 反斜杠 / 空白；一库一账号，仅授权本库
创建时若 mysqld 未运行会自动拉起（首次含初始化约需数十秒），完成后空闲自动回收

数据库运行时

启用数据库
按需启动：连接到达才拉起 mysqld，空闲自动停止，不用时零内存占用
默认 3306；插件内置唤醒代理，mysqld 本身不监听网络
无活跃连接超过该时长后，mysqld 自动停止释放内存（数据保留在磁盘）

SSL 证书自动申请

登录 zerossl.com → Developer → 复制 API Key；插件会自动换取 EAB 凭据
默认 80：CA 会回源访问 http://域名/.well-known/acme-challenge/ 验证域名归属； 若公网 80 已转发到主监听端口可填 0
到期自动续期
每 12 小时巡检，剩余天数不足时自动重新签发
从公网多节点探测 80 端口是否可达，提前发现 NAT 未映射/防火墙拦截问题
使用条件：域名已解析到本服务器，且 80 端口可从公网访问 （NAT 环境请在服务商后台把公网 80 转发到本插件）。通配符证书需 DNS 验证，暂不支持自动申请。
